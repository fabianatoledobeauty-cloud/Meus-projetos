# Roteiro de lançamento das fundadoras

Uma etapa por vez. Só passe para a próxima quando a anterior estiver feita.

## 1. Liberar a página (5 minutos)

- Abra a página de cadastro: https://claude.ai/artifact/KjQKmVpsTk4HEHvpbk9ELz
- Toque em Compartilhar e crie um link público.
- O Painel das Fundadoras NÃO deve ser compartilhado. Ele é só seu: https://claude.ai/artifact/7ZkaG2fEZuuV4Vp2rp5Gwm

## 2. Teste real com 3 pessoas (1 dia)

Mande o link para 3 pessoas de confiança, de preferência uma com iPhone e uma com Android. Peça para cada uma:

1. Abrir o link no celular, sem estar logada no Claude.
2. Preencher como profissional (pode inventar os dados).
3. Tocar em "Enviar pelo WhatsApp" e enviar a mensagem.
4. Te contar se alguma coisa ficou estranha, travou ou não entendeu.

Você confere:

- As 3 mensagens chegaram no WhatsApp (11) 91494-4362, completas?
- Copie cada uma e cole no Painel das Fundadoras. O painel organizou certo?
- Depois do teste, exclua os 3 cadastros de teste do painel.

Se algo der errado, mande um print para o Claude antes de seguir.

## 3. Convite (1 semana)

- Dia 1: mensagem no grupo de alunas e stories (textos em mensagem-alunas.md).
- Dia 2 e 3: mensagem individual para as alunas mais próximas e mais ativas.
- Convite ao vivo no fim de cada curso das próximas turmas.
- Todo cadastro que chegar: copiar, colar no painel e responder a aluna em até 24 horas.

## 4. Meta para seguir para o piloto

- 30 profissionais
- 15 estúdios e salões
- 3 marcas ou escolas

O painel mostra o progresso e os bairros com mais profissionais. Os bairros do topo são os do piloto.
