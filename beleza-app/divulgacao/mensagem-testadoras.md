Mande para 3 pessoas de confiança (de preferência uma com iPhone e uma com Android), depois de criar o link público da página de cadastro.

---

Oi, [NOME]! Preciso de um favorzinho rápido, leva 3 minutos. 🙏

Estou lançando um app de beleza e, antes de mandar para as minhas alunas, quero testar a página de cadastro com pessoas de confiança.

1. Abra este link pelo celular: https://claude.ai/artifact/KjQKmVpsTk4HEHvpbk9ELz
2. Preencha como se fosse uma profissional (pode inventar os dados, só o telefone precisa ter formato de celular).
3. No fim, toque em "Enviar pelo WhatsApp" e envie a mensagem que aparecer.
4. Me conte: travou em alguma parte? Ficou alguma dúvida? Achou alguma coisa estranha?

Se puder, me manda um print de qualquer coisa esquisita. Obrigada! 💗
